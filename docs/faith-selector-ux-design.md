## 一、設計總覽

### 1.1 設計哲學

聖所目前是基督教版本：**深色星空＋金色**，關鍵詞是「夜、星、榮光、永恆」——一種仰望穹蒼的神聖感。

多信仰擴展的核心設計決策：**每條信仰之路是獨立的「聖殿」，不是換膚**。用戶選擇的不只是顏色，而是一整套氛圍、象徵、呼吸節奏。切換信仰時要有「跨過門檻」的儀式感，而不是像切換 App 設定。

### 1.2 信仰之路一覽

| 之路 | 信仰 | 狀態 | 代表色 | 象徵 | 氛圍關鍵詞 |
|------|------|------|--------|------|------------|
| 十字架之路 | 基督教 | 已開放（現有） | 聖金 #f59e0b | 十字架、星空 | 夜、星、榮光、永恆 |
| 蓮花之路 | 佛教 | 本次新增 | 蓮粉 #f0a6c0 | 蓮花、晨霧 | 晨、霧、蓮、呼吸 |
| 太極之路 | 道教 | 即將到來 | 玉青 #5eead4（預留） | 太極、雲山 | 雲、山、自然、無為 |
| 星月之路 | 伊斯蘭教 | 即將到來 | 月銀 #cbd5e1（預留） | 新月、幾何紋 | 夜、沙漠、幾何、靜謐 |

### 1.3 技術約束（給工程師的邊界）

- 主題切換必須用 **CSS 變數**（`:root` 上的 `--faith-*`），整站顏色只引用變數，不寫死 hex。這是平滑過渡的前提。
- 選擇器與過渡動畫必須支援 `prefers-reduced-motion`（減少動態模式下降級為淡入淡出）。
- 選擇結果存 `localStorage`（key 建議：`sanctuary_faith`，值：`christian` / `buddhist`）。
- 響應式：桌面四卡並列，手機改為垂直排列（卡片全寬）。

## 二、信仰選擇器（Faith Selector）

### 2.1 出現時機與定位

- **首次進入網站**（`localStorage` 無 `sanctuary_faith`）時全屏出現。
- 定位：**入殿儀式**，不是彈窗廣告。沒有關閉叉叉——選擇本身就是進入。但提供低調的「隨緣進入」文字鏈（見 2.5），不困住用戶。
- 之後可隨時從右上角切換（見 2.6）。

### 2.4 互動規格

- **Hover（可點卡片）**：卡片上浮 8px，邊框變為代表色 40% 透明度，圖標發光（代表色光暈），過渡 0.4s ease-out。
- **點擊**：卡片先有 0.3s 的「被選中」狀態（代表色邊框全亮＋輕微縮放 0.97），然後進入切換過渡儀式（見第四章）。
- **鎖定卡片**：灰階（`grayscale`），透明度 40%，中央一個小鎖頭圖標＋「即將到來」徽章；hover 時輕微搖晃（表示不可點），不觸發任何跳轉。
- **鍵盤**：左右方向鍵在可點卡片間移動焦點，Enter 選中；焦點框用代表色。

### 2.5 「隨緣進入」

- 選擇器底部一個極低調的文字鏈：「隨緣進入 →」/ "Enter as guest →"。
- 點擊後默認進入基督教之路（現有體驗），並記住選擇，用戶之後可切換。
- 目的：不讓選擇困難的用戶卡在門口。

### 2.6 右上角切換器

- 位置：現有右上角按鈕群組旁（語言切換 EN/中文、選單按鈕同一列）。
- 樣式：圓形小按鈕，圖標為**當前信仰的象徵**（十字架/蓮花線稿），直徑 40px，深色玻璃擬態。
- 點擊：展開一個小浮層（不是全屏），列出四條路（同卡片設計的迷你版，橫向 2×2），當前選中的有代表色邊框；鎖定的顯示「即將到來」。
- 切換後：觸發過渡儀式（見第四章），然後記住新選擇。

## 三、佛教之路視覺主題規範（蓮花之路）

### 3.1 主題概念：一夜星空 vs 一晨霧

基督教是「夜」——仰望星空的神聖。
佛教是「晨」——霧散蓮開的覺醒。

這個對比是整個多信仰設計的靈魂：**同一個聖所，夜晚屬於星空，清晨屬於蓮池**。用戶一切換，時間彷彿從深夜走到了破曉。

### 3.2 顏色規範

| 用途 | 名稱 | Hex | 說明 |
|------|------|-----|------|
| 背景主色 | 墨青 | `#101c1c` | 深青墨色，保持深色模式，但透著青綠而非基督教的藍黑 |
| 背景次色 | 霧灰 | `#1e2a28` | 卡片、浮層底色 |
| 主強調色 | 蓮粉 | `#f0a6c0` | 取代基督教聖金的所有位置：按鈕、邊框、圖標 |
| 次強調色 | 晨金 | `#e8c87a` | 破曉的暖金，比基督教的 `#f59e0b` 更柔、更粉；用於經文出處、次要高光 |
| 文字主色 | 月白 | `#f5f0e8` | 暖白，比基督教的冷白更溫潤 |
| 文字次色 | 青灰 | `#8fa3a0` | 次要文字、placeholder |
| 分隔線 | 霧線 | 白 8% 透明度 | 邊框、分隔線 |
| 成功/平靜 | 竹青 | `#7fb69e` | 如需功能色（暫少用） |

**CSS 變數對照**（工程師實作時）：

| 變數名 | 基督教值 | 佛教值 |
|--------|----------|--------|
| `--faith-bg` | `#0a0a12`（星夜黑） | `#101c1c`（墨青） |
| `--faith-bg-soft` | `#14141f` | `#1e2a28` |
| `--faith-primary` | `#f59e0b`（聖金） | `#f0a6c0`（蓮粉） |
| `--faith-secondary` | `#fbbf24` | `#e8c87a`（晨金） |
| `--faith-text` | `#fafafa` | `#f5f0e8`（月白） |
| `--faith-text-dim` | `#a1a1aa` | `#8fa3a0`（青灰） |
| `--faith-glow` | `rgba(245,158,11,0.3)` | `rgba(240,166,192,0.3)` |

### 3.3 字體建議

- **標題**：Noto Serif TC，600 weight，字距 0.3em。與基督教同一字體家族（保持品質一致性），但行文更疏朗。
- **內文**：系統無襯線（與現有保持一致），可讀性優先。
- **經文引用**：Noto Serif TC 斜體或 500 weight，字級放大 1.2 倍，行高 2.0——營造「讀經」的緩慢感。
- **英文**：Cormorant Garamond（標題）＋ Inter（內文），與中文襯線氣質相配。

### 3.4 象徵圖形

| 場景 | 圖形 | 說明 |
|------|------|------|
| 主象徵 | 蓮花線稿 | 5–8 瓣，1.5px 描邊，蓮粉色；用於選擇器、切換過渡、結果頁水印 |
| 載入動畫 | 水波紋 | 同心圓由中心擴散（像水滴入池），取代基督教的星光脈衝 |
| 領受按鈕 | 圓相（Enso） | 禪宗圓相筆觸，作為「領受祝福」按鈕的背景環；點擊時圓相描繪動畫 |
| 分隔裝飾 | 念珠點 | 一串小圓點（7 顆）作為段落分隔，取代基督教的直線 |
| 背景紋理 | 遠山剪影 | 底部極淡的水墨山形剪影（SVG），透明度 5–8% |

### 3.5 氛圍關鍵詞與背景

- **關鍵詞**：晨霧、蓮池、竹影、月光、留白、呼吸感
- **背景**：深色基底上，一層極緩慢橫向漂移的霧效（CSS 漸層＋`blur`，動畫週期 20 秒）；底部遠山剪影；零星幾點「螢火/晨露」微光（取代星空的繁星，但更少、更暖）。
- **與基督教的區隔**：基督教是「向上看」（星空、穹蒼、光束下照）；佛教是「平視/內觀」（水平霧氣、水面、呼吸）。動效方向：基督教多為垂直（光降下、星上升），佛教多為水平（霧漂移、漣漪擴散）。

### 3.6 組件級規格（工程師直接用）

| 組件 | 基督教現狀 | 佛教版本 |
|------|------------|----------|
| 心情膠囊 | 冷玻璃＋hover 聖金光暈 | 暖玻璃＋hover 蓮粉光暈；圖標不變 |
| 模式切換（恩典/真理） | 恩典 vs 真理 | 改為「禪定 / 智慧」？（見下方註） |
| 輸入框 | 黑 40%＋聖金聚焦邊框 | 黑 40%＋蓮粉聚焦邊框 |
| 領受祝福按鈕 | 聖金實心 | 蓮粉實心，配圓相描繪動畫 |
| 經文卡 | 聖金邊框＋星空背景 | 蓮粉邊框＋晨霧背景＋蓮花水印 |
| 三段標題 | 光中的應許/靈魂的指引/最終的祝福 | 晨光中的偈語/心靈的指引/最終的祝福（文案待定，見註） |
| 禱告卡 | 「專屬禱告」 | 「迴向文」或「祈願文」（文案待定） |
| 載入文字 | 正在傾聽…/感知重量… | 正在觀照…/感知呼吸…/晨霧漸散… |

> **註**：模式與文案的佛教化（恩典→？、禱告→迴向）涉及產品定義，建議與內容團隊（AI 人格設計）共同定案。本方案只規範視覺層，文案以「待定」標示，不擅自決定宗教表述。

### 3.7 動效語言

| 場景 | 動效 | 參數 |
|------|------|------|
| 頁面載入 | 蓮花綻放 | 花瓣 SVG 從閉合到展開，1.8s ease-out |
| 背景 | 晨霧漂移 | 兩層霧效反向緩慢移動，週期 20s/32s，無限循環 |
| 按鈕呼吸 | 呼吸節奏 | 主按鈕 4s 一次的輕微縮放（吸氣 1.0→1.03，呼氣回來），呼應禪修呼吸 |
| 載入中 | 水波紋 | 同心圓擴散，1.5s 一圈，無限循環 |
| 文字出現 | 霧散 | 文字從模糊＋低透明度漸變清晰（`blur(4px)→0`，1s），像霧散見字 |
| 切換段落 | 漣漪 | 新段落出現時帶一個極淡的擴散圓環 |

## 四、信仰切換過渡動效（Transition Ritual）

### 4.1 設計目標

切換信仰不是「換佈景主題」，而是「走進另一座聖殿」。過渡本身是一場 2.5 秒的微型儀式。

### 4.2 四階段分鏡

```
階段 1｜霧起 (0 – 0.8s)
  當前內容整體淡出（opacity → 0，0.6s）
  一層霧效從底部升起，覆蓋全屏（該信仰的霧色：佛教用青白霧）
  
階段 2｜顯聖 (0.8 – 1.6s)
  霧中央，信仰象徵以「描繪動畫」出現
  （佛教：蓮花線稿用 stroke-dashoffset 自我繪製，1s）
  象徵下方浮現雙語名稱：
    蓮花之路
    THE LOTUS PATH
  （字距 0.4em，淡入＋輕微上升）
  
階段 3｜轉境 (1.6 – 2.4s)
  :root 的 --faith-* 變數開始過渡（transition: 1.2s）
  背景從舊主題色 cross-fade 到新主題色
  象徵圖形化作微粒/霧氣散去
  
階段 4｜入殿 (2.4 – 2.8s)
  霧效向上散去，新主題的首頁內容淡入
  完成
```

### 4.3 工程實作要點

- 用一個全屏 `FaithTransition` overlay 組件承載階段 1–3，與主內容解耦。
- 主題切換 = 改 `:root` CSS 變數，靠 `transition: background-color 1.2s, color 1.2s` 自動 cross-fade。**所有信仰相關顏色必須走變數**，這是硬性要求。
- 象徵描繪動畫：SVG `path` 用 `stroke-dasharray` + `stroke-dashoffset` 做自繪效果。
- 時序用 JS 控制（`setTimeout` 鏈或 Web Animations API），不要只靠 CSS delay，方便與 `prefers-reduced-motion` 整合。
- 減少動態模式：四階段壓縮為一次 0.5s 淡入淡出＋直接換主題。

### 4.4 音效（可選）

- 基督教：現有的環境音（延續）。
- 佛教：可加入一聲磬/缽的泛音（切換完成時，音量極低）。若無合適音源，先靜音上線，不阻塞。

## 七、設計決策記錄

1. **為什麼佛教是「晨」不是「夜」**：與基督教星空形成時間對比（夜→晨），切換時有「天亮了」的敘事感，且晨霧、蓮池是台灣人最熟悉的佛教意象。
2. **為什麼主色是蓮粉不是金色**：基督教已佔用金色；蓮粉在深色背景上有同等神聖感，且與「蓮花之路」命名直接呼應。
3. **為什麼選擇器沒有關閉鈕**：這是入殿儀式，不是廣告。但用「隨緣進入」保證不困住用戶。
4. **為什麼過渡要 2.5 秒**：太短像跳轉，太長像 loading。2.5 秒是「儀式」的最小完整單位。
5. **文案未定案的部分**（模式名、迴向文等）刻意留白，需宗教學/內容判斷，UX 不越界。
